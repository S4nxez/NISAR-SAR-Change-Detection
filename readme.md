Muchos creen que las ciudades son demasiado caóticas para medirlas desde el espacio debido al ruido de la actividad humana. Demostramos lo contrario: utilizando la interferometría de dispersores persistentes (PS-InSAR) con los datos de banda L de NISAR, convertimos cada edificio y rascacielos en una estación meteorológica geodésica. No nos molestan las tuberías ni el agua subterránea; al contrario: usamos el radar para desenmascarar cómo la gestión hídrica humana está fracturando la estabilidad de las ciudades a escala de manzana, antes de que ocurra una catástrofe.
