# Project guidelines

## Language

Everything generated in this repository must be written in **English**. This applies to:

- Frontend: UI text, labels, tooltips, error messages, page titles, `lang` attributes.
- Backend and processing code: identifiers, comments, docstrings, log and error messages.
- API responses and report output (HTML, Markdown, CSV, GeoJSON properties).
- Documentation: README, files under `docs/`, PR descriptions and commit messages.
- Tests and test names.

Existing Spanish content may be translated when the file is touched, but do not
rewrite untouched files just to translate them unless asked.
